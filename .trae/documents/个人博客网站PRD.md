# 个人博客网站产品需求文档

## 1. 产品概述

一款现代化的个人博客网站，支持文章发布、分类管理和内容检索功能。
- 为博客作者提供简洁高效的内容管理平台
- 为读者提供优雅舒适的阅读体验
- 采用响应式设计，适配桌面端和移动端

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客 | 无需注册 | 浏览文章、搜索内容、查看分类标签 |
| 管理员 | 系统预设 | 发布/编辑/删除文章、管理分类标签、管理后台操作 |

### 2.2 功能模块

1. **首页**: 文章列表展示、搜索功能、导航栏
2. **文章详情页**: 文章正文展示、分类标签、相关文章推荐
3. **分类标签页**: 按分类或标签筛选文章
4. **管理后台**: 文章CRUD、分类标签管理、登录认证
5. **关于页面**: 博主介绍、联系方式

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 导航栏 | Logo、菜单链接（首页、分类、关于）、搜索框入口、管理后台入口 |
| 首页 | 英雄区 | 博客标题、个人简介、美观的背景设计 |
| 首页 | 文章列表 | 卡片式展示，包含标题、摘要、发布日期、分类标签、阅读量 |
| 首页 | 搜索功能 | 支持标题和内容的全文搜索 |
| 文章详情页 | 文章正文 | Markdown渲染、代码高亮、图片展示 |
| 文章详情页 | 文章信息 | 作者、发布日期、分类、标签、更新时间 |
| 文章详情页 | 相关文章 | 基于同分类或标签推荐3篇相关文章 |
| 分类标签页 | 标签云 | 可视化展示所有标签，点击可筛选 |
| 分类标签页 | 分类列表 | 分类名称和文章数量，点击可筛选 |
| 管理后台 | 登录页 | 用户名密码登录验证 |
| 管理后台 | 仪表盘 | 文章统计、快速操作入口 |
| 管理后台 | 文章管理 | 文章列表、新建/编辑/删除操作、状态筛选 |
| 管理后台 | 编辑器 | Markdown编辑器、实时预览、分类标签选择、封面图上传 |
| 管理后台 | 分类标签管理 | 新增/编辑/删除分类和标签 |

## 3. 核心流程

### 3.1 读者浏览流程

```
访客访问首页 → 浏览文章列表 → 点击文章标题 → 阅读文章详情
                    ↓
              使用搜索功能 → 查看搜索结果 → 选择文章阅读
                    ↓
              点击分类/标签 → 查看筛选结果 → 选择文章阅读
```

### 3.2 管理员发布文章流程

```
管理员登录 → 进入管理后台 → 点击新建文章 → 编写内容
                                          ↓
                                   选择分类和标签
                                          ↓
                                   设置封面图（可选）
                                          ↓
                                   预览文章 → 确认发布
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 暖白背景 (#FAF9F6) + 深灰文字 (#2D3436) + 橙色点缀 (#E17055)
- **按钮样式**: 圆角设计，轻微阴影，悬停时颜色加深
- **字体**: 
  - 标题: 使用具有文艺感的衬线字体
  - 正文: 清晰易读的无衬线字体
  - 代码: 等宽字体
- **布局风格**: 杂志风格，卡片式布局，大量留白
- **图标风格**: 简约线条图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 英雄区 | 全屏背景渐变、大号标题动画入场、副标题淡入效果 |
| 首页 | 文章列表 | 3列网格布局(桌面端)、卡片悬停上浮效果、图片懒加载 |
| 文章详情页 | 正文 | 居中排版(最大宽度700px)、优雅的段间距、代码块深色背景 |
| 管理后台 | 编辑器 | 左右分栏(编辑区+预览区)、工具栏、保存按钮固定底部 |

### 4.3 响应式设计

- **桌面端优先**: 以1440px为设计基准
- **平板适配**: 768px-1024px，文章列表调整为2列
- **移动端**: 小于768px，单列布局，汉堡菜单，触摸友好的按钮尺寸
- **动画优化**: 移动端减少复杂动画，提升性能
